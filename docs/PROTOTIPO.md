# Protótipo — Dona Clara

## Fluxo principal

```text
INÍCIO
  ↓
CATÁLOGO DE PRODUTOS
  ↓
ADICIONAR AO CARRINHO
  ↓
CONFERIR PEDIDO
  ↓
INFORMAR NOME + DATA + HORÁRIO
  ↓
CONFIRMAR ENCOMENDA
```

## Fluxo para empresas

```text
INÍCIO
  ↓
COFFEE BREAK
  ↓
SOLICITAR ORÇAMENTO
  ↓
E-MAIL / CONTATO COMERCIAL
```

## Decisões de interface

- Tons terrosos remetem ao artesanal e à panificação.
- Tipografia serifada nos títulos reforça tradição e proximidade.
- Botões de ação possuem alto contraste.
- Layout responsivo prioriza celular.
- Informações de pedido ficam concentradas em uma etapa simples.
